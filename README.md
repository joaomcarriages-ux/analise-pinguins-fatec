# 🐧 Análise Exploratória de Dados: Palmer Penguins

Trabalho prático desenvolvido para a matéria de **Princípios de Ciência de Dados** na **FATEC Cotia**. 

O objetivo deste projeto foi realizar uma análise exploratória completa utilizando o clássico dataset *Palmer Penguins*, aplicando técnicas de manipulação de dados e visualização estatística em Python.

## 🛠️ Tecnologias e Ferramentas
* **Ambiente:** Google Colab
* **Linguagem:** Python
* **Bibliotecas:** Pandas, Matplotlib, Seaborn
* **Suporte de IA:** Utilização de prompts estruturados para apoiar na escrita do código e na estruturação lógica da análise.

## 📊 Etapas da Análise e Visualizações
1. **Limpeza e Preparação:** Tratamento inicial dos dados e verificação de valores ausentes no dataset.
2. **Visualização Gráfica:** 
   * Construção de **Boxplots** para analisar a distribuição de variáveis físicas (como massa corporal e comprimento do bico) entre as diferentes espécies (*Adelie*, *Chinstrap* e *Gentoo*).
   * Criação de **Gráficos de Dispersão (Scatter Plots)** para identificar correlações e clusters anatômicos.
3. **Análise Crítica:** Condução das perguntas analíticas, definição de limites para as consultas e interpretação dos padrões encontrados nos gráficos.

## 🚀 Como Visualizar
Você pode explorar o código completo, os blocos de execução e os gráficos interativos clicando no arquivo `.ipynb` listado neste repositório!
